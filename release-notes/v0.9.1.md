# Nocto 0.9.1 (Linux hotfix)

Linux only; Windows stays on 0.9.0.

- Snapdragon (V4L2 Iris) hardware recordings on ARM Linux are playable again: MKV and MP4 files were empty or unplayable
- Fixed a crash when exporting with the YouTube 4K preset (or any preset on the Auto encoder); exports now fall back to the software encoder with a clear message if the hardware encoder can't handle the size
- Fixed stutter in hardware-encoded HEVC/H.264 recordings of content below 60 fps
