# Nocto 0.4.1

## New
- **Editor workspace button.** A large **Editor** button now sits next to **Stream** in Controls. Inside the editor, the same spot shows **Back to Record**.
- **Workspace hotkey.** Use "Switch Record / Editor workspace" (Settings > Hotkeys) to switch between the Record and Editor workspaces.
- **Support Nocto on Patreon.** Help > Support Nocto on Patreon... and a button in Help > About Nocto open https://www.patreon.com/noctoapp in your browser.

## Fixes
- Fixed the ImGui "conflicting ID" error caused by the Record/Edit tabs next to the Edit menu. The tabs have been removed from the menu bar.
- **Window Capture now works when two windows have the same title.** Lists built from runtime data now use stable IDs: windows (HWND/PID), games, app audio, displays, cameras, audio devices, GPUs, encoders, plugin sources and scene hotkeys.
- Entries with the same name now show a disambiguator, e.g. "PowerShell (PID 1234)", "Test Camera (2)".

## Internal
- New UI ID audit (`Nocto.exe --test-ui-ids`). It drives every window, menu, popup and combo with synthetic duplicate data and fails on any duplicate ImGui ID.
