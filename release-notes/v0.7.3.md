# Nocto 0.7.3: Linux

**Linux only. Windows users stay on 0.7.0** (there is no Windows 0.7.1, 0.7.2 or 0.7.3 and the Windows updater is not affected).

Download `Nocto-0.7.3-x86_64.AppImage` (Linux x86_64, then `chmod +x` and run it).

**Changes**
- Window Capture now works on Linux: pick the window with the new "Choose window..." button (your desktop's own window picker opens)
- Display Capture and Window Capture properties can reopen the picker to switch to another screen or window later
- AppImage self-update: Nocto downloads the new AppImage, verifies its SHA-256 checksum, keeps a backup of the old one, restarts itself, and goes back to the previous version automatically if the new one fails to start

**If you are on 0.7.2 or older:** download this version manually once. After that, updates install from inside Nocto.
