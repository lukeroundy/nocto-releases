# Nocto 0.5.3: Windows on ARM

**New: native Windows ARM64 build** for Snapdragon X laptops (Windows 11 on ARM). Download `Nocto-Setup-0.5.3-arm64.exe`; everyone else keeps using `Nocto-Setup-0.5.3.exe`.

- Records with the Qualcomm hardware encoder (H.264 and AV1 on Snapdragon X)
- Browser sources, the virtual camera, plugins and the editor all run natively
- Game capture hooks x64 games running under emulation and 32-bit games; the virtual camera works in both ARM64 and x64 apps

**Fixes and improvements (all platforms)**
- Fixed a crash when finishing some MP4 recordings (a memory bug in the MP4 finalize step)
- Encoder fallback: if the encoder saved in your settings isn't available on this PC (e.g. NVENC on a non-NVIDIA GPU), Nocto now uses the best available one instead of failing to record
- New software H.264 (CPU) encoder, used when the GPU has no hardware encoder
- Encoders that are installed but can't actually start are no longer offered
- Updater: each architecture now gets its own installer. ARM64 installs only ever update to ARM64 builds, and x64 Nocto running on an ARM PC is offered the native ARM64 build

**Known limits on ARM64**
- Native ARM64 games use window capture (hook capture isn't available for ARM64 apps yet)
- 32-bit Vulkan game capture delivers frames that don't update; use window capture for those games
- HEVC on Snapdragon needs "HEVC Video Extensions" from the Microsoft Store; without it, H.264 and AV1 are offered
