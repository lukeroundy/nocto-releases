# Nocto 0.8.0: Twitch plugin, Plugin SDK 2 and the plugin library

Download `Nocto-Setup-0.8.0.exe` (Windows x64), `Nocto-Setup-0.8.0-arm64.exe` (Windows on ARM) or `Nocto-0.8.0-x86_64.AppImage` (Linux x86_64, then `chmod +x` and run it; if you already run 0.7.3, Nocto updates itself from inside the app).

**Windows:** this is the first Windows update since 0.7.0 (the Linux-only 0.7.1 to 0.7.3 releases did not change Windows). The installer updates your existing install and keeps your settings.

**Twitch plugin (separate download)**
- Sign in to Twitch from inside Nocto with a device code: Nocto shows a short code, you approve it on twitch.tv, and no password or stream key is typed into Nocto. Your login is stored in Windows Credential Manager (Linux: the desktop keyring)
- Stream info editor: change your stream title, category, tags and language from a dock next to your preview
- Chat dock: read and send chat without opening a browser (if the live connection is unavailable it falls back to read-only chat)
- Get it from the new plugin library (below) or from the Plugins page on the website. Windows x64, Windows ARM64 and Linux x86_64 builds are available

**In-app plugin library (File > Plugins...)**
- "Install from .zip..." installs a plugin from a zip file. Nocto checks the whole file first, shows you exactly which files it will install, and asks before installing. The plugin is ready after you restart Nocto
- "Browse plugins..." opens the plugin library. Press "Load plugin list" to see the available plugins; "Install" downloads the plugin, checks it against its published SHA-256 checksum and installs it. Nothing is downloaded until you press the button
- "Remove" uninstalls plugins you installed
- No terminal commands are needed for any of this

**Plugin SDK 1.1 (ABI 2) for plugin authors**
- Plugins can now add their own docks and panels (with the layout remembered), menu items, a settings document and secret storage (tokens and passwords live in the OS credential store, never in your profile)
- Asynchronous HTTPS requests and WebSockets, timers, and opening links in the browser, all without blocking Nocto's UI
- Existing ABI 1 plugins keep working without a rebuild
- Docs and the SDK 1.1 download: https://lukeroundy.github.io/nocto-releases/plugins.html

**Linux**
- Includes everything from 0.7.1 to 0.7.3 (window capture picker, camera driver one-click setup, AppImage self-update with checksum, backup and automatic rollback)
- Plugins work like on Windows: Twitch and any plugin from the library installs into `~/.local/share/Nocto/plugins`

**Known limits**
- The Twitch plugin needs you to sign in with your own Twitch account; it asks only for the permissions to edit your channel's stream info, read chat and send chat
- Plugins load when Nocto starts, so restart Nocto after installing or removing one
- Windows x64, Windows ARM64 and Linux limits from 0.7.0 still apply (no game capture hook on Linux, HDR10 output is SDR on Linux)
