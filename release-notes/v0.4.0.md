# Nocto 0.4.0

**Download:** [Nocto-Setup-0.4.0.exe](https://github.com/lukeroundy/nocto-releases/releases/download/v0.4.0/Nocto-Setup-0.4.0.exe)
SHA256: `189f6b9bee3337f51fa8f6a3b60bd782125e553f067cbe6e6e10806dd0798647`

## New
- Nocto Virtual Camera (DirectShow; works in 32- and 64-bit apps)
- Recording pause/resume (hotkey + UI), seamless timestamps
- Plugin SDK: native source plugins and HLSL shader filters, sample plugins included
- Replay buffer, multistream to several services at once, HDR metadata fix
- Windows installer (Program Files, Start menu/desktop shortcuts, .gprproj association)
- Auto-updater: checks at startup (toggle in Settings) or Help > Check for updates; verifies SHA256, never updates without asking

## Notes
- Installer is not yet code-signed; SmartScreen may warn ("More info" > "Run anyway").
- Requires Windows 10/11 x64. VC++ runtime is installed automatically if missing.
