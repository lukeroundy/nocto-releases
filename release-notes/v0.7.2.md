# Nocto 0.7.2: Linux hotfix

**Linux only. Windows users stay on 0.7.0** (there is no Windows 0.7.1 or 0.7.2 and the Windows updater is not affected).

Download `Nocto-0.7.2-x86_64.AppImage` (Linux x86_64, then `chmod +x` and run it).

**Fixes**
- The virtual camera no longer freezes the program for about 5 seconds when you start it
- One-click virtual camera driver setup: when the v4l2loopback camera driver is not loaded, Nocto asks once ("Enable", "Enable and load at every startup", or "Use PipeWire camera only") and your desktop's own password dialog loads it, so Discord, Zoom and browsers see "Nocto Virtual Camera" with no terminal commands. If the driver is not installed for your kernel, Nocto shows which package to install. You can reopen it any time in Settings > Output > Virtual camera.

Everything else is identical to 0.7.1 (which also fixed the duplicate, icon-less menu entry).
