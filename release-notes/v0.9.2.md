# Nocto 0.9.2

All platforms: Windows x64, Windows ARM64, Linux x86_64 and Linux aarch64.

- New: pop out the Preview or Program into its own window, or view it fullscreen on any monitor (F11 or double-click toggles fullscreen, Esc leaves it)
- Plugin library: Twitch and Discord plugins now show up on ARM Linux too
- Includes the 0.9.1 Linux fixes: playable Snapdragon hardware recordings on ARM Linux, no more crash exporting with the YouTube 4K / Auto encoder, and smoother hardware HEVC/H.264 recordings
