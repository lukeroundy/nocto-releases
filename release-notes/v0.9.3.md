# Nocto 0.9.3

All platforms: Windows x64, Windows ARM64, Linux x86_64 and Linux aarch64.

- Capture cards: Nocto now matches the card's own audio device by name much more reliably (generic words like "USB" no longer pick an unrelated microphone), and ticking "Capture audio" picks it for you
- The capture card's properties show a warning when no audio device is chosen, or when the chosen one is not connected
- Windows: more detailed audio capture logging (device format, open errors and whether the device delivers any sound in the first seconds) to help track down capture cards that record no audio
