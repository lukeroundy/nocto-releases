# Nocto 0.7.0: editor menus, linked audio, scene and profile sharing, OBS import

Download `Nocto-Setup-0.7.0.exe` (Windows x64), `Nocto-Setup-0.7.0-arm64.exe` (Windows on ARM) or `Nocto-0.7.0-x86_64.AppImage` (Linux x86_64, then `chmod +x` and run it).

**Video editor**
- Right-click menus on clips, the timeline, the media bin and the program monitor: enable/disable, lock, solo, duplicate, copy and paste, link or detach audio, add marker here, and more
- Separate audio from video: "Detach audio" turns a clip's sound into its own audio clip, and linked audio and video clips move, trim and delete together; "Link audio" ties them back
- Audio waveforms and frame thumbnails (filmstrips) on timeline clips, drawn in the background and kept in a disk cache so reopening a project is instant

**Share your setup**
- Export and import scenes (`.nocto-scenes`): File > Scenes & profile, or right-click a scene > "Export scene...". The import dialog lets you choose which scenes to bring in
- Export and import your full profile (`.nocto-profile`): settings, scenes and the dock layout. Stream keys and other secrets are never written to the file, and are stripped again on import; images are found again next to the file if the folder moved
- Import an OBS Studio scene collection (File > Scenes & profile > Import OBS Studio scene collection). Scenes, groups and nested scenes, positions, sizes, crops, flips, display/window/webcam/image/color/browser/text sources, audio devices, and common filters (color correction, chroma key, sharpen, crop, gain, noise gate, noise suppression, compressor/limiter) are converted. A report lists everything that was approximated, skipped or missing

**Linux packaging**
- The AppImage now has a proper icon at every size and AppStream metadata, so it shows up correctly in app menus and software centers

**Known limits**
- OBS import is best-effort: transitions and hotkeys are not imported; media, VLC, NDI and other plugin sources are skipped; slideshows keep only their first image; OBS text sources become a browser source (approximate look); an item whose native size OBS did not store is placed approximately; rotation is rounded to quarter turns; crop and bounds on groups and nested scenes are approximated. Check the import report
- Importing a profile applies the saved dock layout; video, audio, output and stream sections can't be imported while recording or streaming
- Windows x64, Windows ARM64 and Linux limits from 0.6.0 and 0.5.3 still apply (no game capture hook on Linux, no in-app updater on Linux yet, HDR10 output is SDR on Linux)
