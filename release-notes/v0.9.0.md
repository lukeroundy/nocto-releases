# Nocto 0.9.0

- Multi-track audio recording with per-source track routing (Windows and Linux)
- Scene transitions, Studio Mode and a live stream-health indicator
- Blur and Pixelate source filters, plus a Pixelate effect in the editor
- Clips and chapter markers; automatic loudness normalization
- Export presets and vertical (9:16) canvas
- Twitch chat overlay, color eyedropper, frame export, Discord plugin
- Compact Controls panel and status bar; new UI scale setting
- Fixed hardware encoder detection
- Linux ARM: V4L2 hardware encoders (with software fallback)
- New: Linux ARM64 (aarch64) AppImage
