# Nocto 0.7.1: Linux hotfix

**Linux only. Windows users stay on 0.7.0** (there is no Windows 0.7.1 and the Windows updater is not affected).

Download `Nocto-0.7.1-x86_64.AppImage` (Linux x86_64, then `chmod +x` and run it).

**Fixes**
- Duplicate, icon-less "Nocto" menu entry: AppImage managers such as Shelly create their own launcher, and Nocto's generated launcher (needed for the screen-share and shortcut portals) now gets the app icon and hides itself from the menu when another launcher for the same AppImage exists
- The launcher icon now persists after you close Nocto (a copy is kept next to the launcher entry instead of pointing into the AppImage's temporary mount)

Everything else is identical to 0.7.0.
