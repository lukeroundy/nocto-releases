# Nocto releases

Public downloads and update feed for **Nocto**, a GPU-first screen/game recorder and streamer for Windows and Linux.
Source code is private; this repository only hosts installers, release notes, `latest.json` (the in-app update feed) and the website.

- Website: https://lukeroundy.github.io/nocto-releases/
- Downloads: https://github.com/lukeroundy/nocto-releases/releases/latest
