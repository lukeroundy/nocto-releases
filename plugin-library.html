How to install

  1. In Nocto open File › Plugins… and press Open user plugins folder.
  2. Copy the plugin's files (from the zip) into that folder. Windows: %LOCALAPPDATA%\Nocto\plugins. Linux: ~/.local/share/Nocto/plugins.
  3. Enable the plugin in the Plugins window (or restart Nocto).

Only install plugins you trust: native plugins run inside Nocto. Each download lists its SHA-256 so you can check the file.
