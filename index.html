Nocto

Record and stream without your frames ever leaving the GPU. Now on Windows and Linux.

Download for Windows

v0.7.0 · Windows 10/11 x64 · all releases

Zero-copy pipeline

Capture, convert and encode on the GPU with NVENC, Intel QSV/Arc and other hardware encoders on Windows. Linux records with QuickSync, VAAPI, NVENC or a software encoder.

Windows and Linux

The same app on both: a Linux AppImage for x86_64 with Wayland and X11 support, PipeWire capture and audio, and the same UI, editor and plugins as Windows.

Anti-cheat safe

Windows.Graphics.Capture by default; opt-in game capture for DX9/11/12, OpenGL and Vulkan.

Replay buffer

Save the last moments with a hotkey, always ready in the background.

Multistream

Go live to several platforms at once from a single encode.

Virtual camera

Use your Nocto scene as a webcam in calls and other apps (on Linux through PipeWire or v4l2loopback).

Pause & resume

Pause recordings and keep one seamless file.

Browser sources

Built-in web engine (Servo) for alerts and overlays, on Windows and Linux.

Plugins

Native source plugins (.dll on Windows, .so on Linux) and shader filters. Plugin SDK docs →

HDR & AV1

HEVC/AV1 hardware encoding with correct HDR metadata.

Share and import

Export scenes or your whole profile (stream keys never included) and import your OBS Studio scene collections.

GPU video editor

Trim, split and export, plus GPU effects with keyframes: color, curves, LUTs, blur, chroma key, masks, titles, shapes, speed ramps, transitions and picture-in-picture.

What's new

0.7.1: Linux hotfix

  • Linux only (Windows stays on 0.7.0): fixes a duplicate, icon-less "Nocto" menu entry when the AppImage is managed by a tool like Shelly, and the launcher icon now persists after you close Nocto

0.7.0: editor menus, linked audio, sharing and OBS import

  • Video editor: right-click menus on clips, the timeline, the media bin and the program monitor (duplicate, copy and paste, lock, solo, markers and more)
  • Separate audio from video: detach a clip's sound into its own audio clip; linked audio and video move, trim and delete together
  • Audio waveforms and frame thumbnails on timeline clips, cached on disk so projects reopen instantly
  • Export and import scenes (.nocto-scenes) or your full profile (.nocto-profile: settings, scenes and dock layout). Stream keys and other secrets are never written to the file
  • Import an OBS Studio scene collection: scenes, groups, transforms, crops, display/window/camera/image/color/browser/text sources, audio devices and common filters, with a report of anything approximated or skipped
  • Linux AppImage: proper icon at every size and AppStream metadata
  • Limits: OBS transitions, hotkeys and media/VLC/NDI sources are not imported; text sources become browser sources; placement of items with unknown size is approximate. Linux limits from 0.6.0 still apply

0.6.0: Nocto for Linux

  • First Linux release: an AppImage for x86_64, tested on CachyOS with KDE Plasma on Wayland. Download, chmod +x and run
  • Screen and window capture through the desktop portal and PipeWire; desktop and microphone audio through PipeWire
  • Recording and streaming with Intel QuickSync, VAAPI, NVIDIA NVENC or software x264/x265, with an encoder list that follows the GPU you pick; RTMP and SRT streaming and the replay buffer
  • The same UI as Windows, plus the video editor with GPU effects, plugins (.so), Servo browser sources, HDR source tone-mapping, webcam and capture cards (V4L2), a virtual camera, global hotkeys and native file dialogs through the desktop portal
  • Limits on Linux: no game capture hook (use window capture), frames still make one trip through system memory (not zero-copy yet), HDR10 output is SDR only, no in-app updater yet (download new versions here), WebAudio isn't supported in browser sources, and page audio needs the GStreamer plugins-base and plugins-good packages. Discord and Zoom see the virtual camera only with v4l2loopback
  • Windows (x64 and ARM64) behaves as in 0.5.3

0.5.3: Windows on ARM

  • Native Windows ARM64 build for Snapdragon X laptops: Qualcomm hardware H.264 and AV1 recording, browser sources, virtual camera, plugins and the editor
  • Game capture hooks x64 (emulated) and 32-bit games on ARM; native ARM64 games use window capture
  • Fixed a crash when finishing some MP4 recordings
  • If the saved encoder isn't available on this PC, Nocto uses the best one that is; new software H.264 fallback
  • Each architecture gets its own updates
  • Known limits on ARM64: 32-bit Vulkan game capture doesn't update frames; HEVC needs "HEVC Video Extensions" from the Microsoft Store

0.5.2: sharp, uncluttered UI at every display scale

  • Works at every Windows display scale from 100% to 300%, and in small windows
  • Text, logo and icons stay sharp at high DPI; Nocto adapts when moved to a monitor with a different scale
  • Fixed: stats overlapping the Settings button, overlapping timeline track headers and ruler labels, cut-off editor toolbar and transport buttons
  • Settings, mixer, sources, inspector and the multistream list fit their content at every scale

0.5.1: AMD recording fix, log dumps and bug reports

  • Fixed: on AMD GPUs, recorded video froze after a few seconds while the audio kept going
  • Encoder watchdog: a stalled hardware encoder is restarted without stopping the recording, and audio stays in sync
  • AMD encoder tuning: low latency, no B-frames, and a quality cap so 100+ fps captures keep up
  • Help > Save log dump: one zip with logs, system and GPU info, stats and redacted settings (no stream keys)
  • Help > Report a Bug opens the GitHub issue form
  • Fresh installs no longer come with a Twitch destination preset
  • Rotating logs and an encoder lag display in the Performance panel

0.5.0: editor effects

  • GPU effect stack per clip: Color Correction (exposure, contrast, saturation, temperature/tint, lift/gamma/gain), Curves, .cube LUTs, Gaussian Blur, Sharpen, Vignette, Film Grain, Chroma Key with spill suppression, Invert
  • Keyframes on every parameter (linear, ease, hold), shown and draggable on the timeline
  • Transform and crop per clip: position, scale, rotation and opacity
  • Transitions: crossfade, dip to black, wipe, slide and zoom
  • Speed changes and keyframed speed ramps, with pitch-preserved or muted audio
  • Title and shape layers, plus rectangle and ellipse masks with feather and invert on any effect
  • Add or remove video and audio tracks for picture-in-picture
  • Plugin video filters show up as editor effects. Docs

0.4.1

  • Editor button next to Stream and a workspace hotkey
  • Fixed duplicate window and device names
  • Support on Patreon links
